# 🚀 AI Job Copilot

An AI-powered assistant that helps automate and optimize the job application process.

---

## 🧠 Features (In Progress)

* ✅ AI Integration (Ollama)
* ✅ Backend API (Spring Boot)
* ✅ Frontend Setup (React)
* 🔜 Job Description Analyzer
* 🔜 Resume Optimizer
* 🔜 Job Automation

---

## 🏗️ Tech Stack

* Backend: Java, Spring Boot
* Frontend: React (Vite)
* Database: PostgreSQL
* AI: Ollama (Local LLM)

---

## 📊 Current Status

🚧 Currently building **Phase 1 — Job Analyzer**

---

## 🎯 Goal

Reduce job application effort using AI and automation.

## 🚀 How to Run

### Backend

```
cd backend
mvnw.cmd spring-boot:run
```

### Frontend

```
cd frontend
npm install
npm run dev
```
